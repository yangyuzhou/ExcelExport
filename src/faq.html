一站式导表工具 · 操作手册

改完表，接下来怎么做？

保存 Excel → 刷新状态 → 增量导表 → 成功后提交 SVN。
第一次使用、找不到表、导表报错，都可以在下面找到操作步骤。

先看快速上手，也可以从左侧选择问题分类。

01 我刚拿到工具，怎么开始？

  1. 先确认自己要改哪个版本

    请同事提供已检出的项目目录，以及该版本的“配置表生成”和导表工具文件夹。只拿到绿色版 exe，还不能替代这些项目文件。

  2. 如果弹出“还差一步”，先装 SVN 组件

    按弹窗步骤安装 command line client tools，再点“已安装，重新检测”。提示消失后再继续；没有安装权限就请项目维护人员协助。

  3. 打开“路径设置”，选好两个文件夹

    设置版本名称、配置表生成目录、工具执行目录。点“保存配置修改”，再点“切换至该版本”，确认右下角版本名正确。

  4. 先用一张需要修改的表完成一次导出

    保存 Excel，回工具点“刷新状态”，确认该表没有标成红色，再点“增量导表”。看到“导表成功”后，按项目流程检查结果并提交 SVN。

02 路径不会选，或者版本选错了

“配置表生成目录”和“工具执行目录”各选哪个？

第一个：选项目里的“配置表生成”文件夹。打开后应该能看到 config.xml。不要选它上一级的 design，也不要选“数据填表”。

design
├─ 配置表生成  ← 第一个选这里
│  └─ config.xml
└─ 数据填表    ← 你平时修改的 Excel 在这里

第二个：选存放 toClientPy1.bat 的文件夹，通常名为 batch。不同项目可能放在不同位置，不确定就请同事指出这个文件的位置。

“执行脚本名称”通常保持默认值。若项目给的是另一个脚本，请按维护人员提供的名称填写。

我有几个分支，怎么避免改错版本？
  1. 打开“路径设置”，点左侧“＋”，给分支取容易区分的名称。
  2. 选择这个分支自己的目录，点“保存配置修改”。
  3. 点“切换至该版本”，看主界面右下角的版本名确认。

只保存配置不会切换当前版本。每个版本的强制增量、不导表选择分别保留，切换后检查一次列表。

提示文件找不到，我应该检查哪里？

先看错误里的文件名和路径：缺 config.xml 就核对第一个目录；缺 .bat 就核对第二个目录和脚本名称；缺 .xlsx 就检查“数据填表”中是否有该文件。

如果是新加的表，先更新 SVN。仍然缺失时，把错误信息发给项目维护人员，确认项目文件齐全和配置中的表名正确。

03 启动就提示缺少 SVN

我已经装了小乌龟，为什么还不能导表？

小乌龟的右键菜单能用，并不代表它的命令行组件也装好了。工具需要这个组件来判断你改过哪些 Excel。

  1. 打开 TortoiseSVN 安装程序。已安装过就选 Modify（修改）。
  2. 在组件列表找到 command line client tools，改成安装到本机，然后完成安装。
  3. 回到工具点“已安装，重新检测”或右侧“重新检测”。
成功后，安装弹窗会关闭，右侧红色提示会消失。还没准备好时，可点“稍后处理，先查看工具”；下次启动仍会提醒。
按步骤装完了，还是提示缺少 SVN？
  1. 关闭导表工具，再重新打开。
  2. 重新检查安装组件列表，确认 command line client tools 不是“不安装”。
  3. 如果装在自定义目录，或没有安装权限，请把红色提示发给项目维护人员，协助检查安装路径。

不要反复点击导表。环境没准备好时，工具不会开始生成文件。

SVN 已装好，但提示“不是工作副本”或状态检测失败？

确认目录是通过 SVN 检出的项目，而不是单独复制的一组 Excel。让同事检查该目录的 SVN 状态；遇到冲突或锁定，先按 SVN 提示处理，再点“刷新状态”。

“更新SVN”用来获取仓库里的修改；“刷新状态”只查看本机哪些文件改过。它们是两件不同的操作。

04 我只想导自己改的表

日常改完 Excel，应该按什么顺序操作？
  1. 在 Excel 或 WPS 里保存修改。
  2. 回工具确认右下角版本，点击“刷新状态”。
  3. 检查本次要导的表：改过的表会标黄；红色块表示不导表。
  4. 点击“增量导表”，等到成功提示。

只有需要重新生成全部配置时才使用“全量导出”。全量也会跳过红色“不导表”的文件。

左边的小方框怎么点？红色块是什么意思？
□ 正常状态根据实际修改情况加入增量。不显示“自动判断”文字。
✓ 第一次点击强制增量：这次也要导它，即使工具没检测到修改。
⊘ 第二次点击不导表：整个红色块，全量和增量都跳过。

第三次点击恢复正常。也可以右键卡片，直接选“设为不导表”或“恢复自动判断”。

选择按整个 Excel 生效。同一个文件的所有页签一起切换，不是只跳过当前看到的一个 Sheet。
为什么昨天标红的表，今天还是不导表？

“不导表”和“强制增量”都会记住，刷新、导表成功、重启也不会自动清除。

需要恢复时，点红色块左侧的禁止符号，让它恢复正常；或者右键选“恢复自动判断”。再点“刷新状态”，按需要导出。

明明改了表，却找不到它，或者提示没有增量？
  1. 先确认 Excel 已保存，而且改的是当前版本里的文件。
  2. 清空搜索、选择“全部表格”，解除筛选。
  3. 点击“刷新状态”，查看有没有 SVN 检测失败提示。
  4. 若这张表是红色块，先恢复正常；确实需要重新导出时，可点一次方框设为强制增量。

05 我想直接打开某个页签

怎么找到表并直接打开 Sheet？

顶部切换到“Sheet 模式”，搜索表名或页签名，找到后点卡片右侧“打开”。工具会打开所属 Excel，并尝试切到这个页签。

“Excel 模式”只打开文件。想定位页签，请使用“Sheet 模式”，或报错卡片里的“打开出错页签”。

文件打开了，但没切到对应页签怎么办？

先看工具提示。若提示软件不支持自动定位，请在 Excel 或 WPS 底部手动选择该页签。

若提示页签不存在，核对是否被改名，联系维护人员修正表配置；若页签被隐藏，请先取消隐藏。如果 Excel 有弹窗等待处理，先处理弹窗再试。

06 导表报错了，我该改哪里？

错误卡片怎么看？以“day 填了 是”为例

先看卡片里的 Excel → 页签 → 字段 → 当前值，不用从一大段日志里猜。

示例：下面这些名称来自某次导表日志

Excel     魔战九州配置表.xlsx
页签      robberyDate
字段      day
要求类型  int（整数）
当前值    是

原因：“day”需要整数，当前填写的是“是”。
  1. 点“打开出错页签”，确认打开的文件和页签与卡片一致。
  2. 找到字段名为 day 的列，检查值为“是”的单元格。可在该列用 Ctrl+F 查找。
  3. 按配置规则填入正确整数。不要仅为了消除报错，随意改成 0 或 1。
  4. 保存 Excel，回工具刷新状态并重新增量导表。
示例中的“是”是填错的值，不是字段名。实际以你本次错误卡片显示的内容为准。

如果“当前值”显示（空值），请检查该字段列中未填写或仅含空白的单元格，按配置规则补充内容，不要直接默认填 0。“日志未提供”表示脚本没有输出这个值，与空值不同；0、false 等实际内容会原样显示。

错误挡住了日志，怎么关掉？关掉还能找回来吗？

点错误卡片右上角的 ×，就能继续查看原位置的日志。日志区域不会变小，日志也不会被清空。

需要再看时点日志右下角“查看最近错误”。重新发起导表后，旧错误卡片会收起，显示新任务的结果。

“索引值不唯一 id=4”是什么意思？

同一个页签里，索引字段 id 的值 4 出现了重复。错误卡片会列出 Excel、页签、字段 id 和重复值 4。

打开出错页签，在 id 列查找 4，核对所有重复记录，并按配置规则修正。保存后重新导表。不要直接按任意键忽略错误，也不要未经核对就删除记录。

提示“输入连接已断开”或 EPIPE，怎么办？

这表示导表进程的输入连接关闭了。工具会停止发送输入，避免反复报错；如果进程最终正常完成，不会误报失败。

若弹出“本次导表未完成”，点“关闭并查看日志”，检查脚本是否被关闭或异常退出。修复原因后可以再次导表。再次发生时，点“复制错误信息”发给维护人员。

如果同时有具体的表数据错误，优先按表名、页签和字段修复。导表失败时可能已生成部分文件，请在重新导表成功后再提交。

没有行号，或者显示“未能识别”，怎么找？

有些项目脚本只输出字段和值，没有 Excel 行号。这时按卡片中的字段名找到列，再查找错误值。值出现多次时，逐一核对。

“脚本行号”可能从 0 开始或没有算表头，不能直接当作 Excel 左边的行号。程序报错中的代码行号也不是 Excel 行号。

如果表名或页签仍无法识别，点“复制错误信息”发给维护人员。工具会带上相关原始日志，避免把上一张表误当作出错表。

我看不懂错误，应该给同事发什么？

点“复制错误信息”，粘贴给项目维护人员，再补充一句：“我在什么版本，改了哪张表，点的是增量还是全量。”复制内容包含版本、错误位置、相关日志和最近运行日志。

重复 ID 或字段值错误通常需要检查 Excel；脚本异常、文件占用、路径不存在等，要按卡片建议处理。不要只发“导表失败”四个字。

报错时可能已经生成了部分文件。先修复并重新导表成功，再检查并提交。
好久没有新日志，是不是卡住了？

先看有没有 Excel、SVN 或脚本窗口等你操作。全量导出可能较慢，运行中不要反复点按钮。

确认长时间不动时，记录当前版本和最后的日志，请维护人员排查。强行关闭后不要直接提交产物，应先重新导表并确认结果。

07 导表成功后，还要做什么？

我看到“导表成功”了，同事就能拿到修改吗？

还需要提交 SVN。导表只是生成了你电脑上的文件。

  1. 点“提交SVN”，核对需要提交的 Excel 和生成文件。
  2. 填写本次修改说明，点“确认并拉起提交”。
  3. 在弹出的 SVN 窗口完成提交，确认 SVN 提示成功。
“不导表”不影响 SVN 提交勾选。红色文件如果不想提交，需要在提交列表中另外取消勾选。
以后从哪里看这个指南？怎么关闭自动弹出？

主界面点“使用指南 / FAQ”，或按 F1。看完点“返回工具”或按 Esc。

首次打开会展示指南。底部不勾选“每次启动都显示”，以后就只在你主动打开时显示。

发给同事时，可以一并发送 exe 旁的 使用指南_FAQ.html，双击即可离线阅读。

没有找到匹配的问题

试试「路径」「SVN」「不导表」「Sheet」「日志」，或点击清除查看全部。
