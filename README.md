# 一站式导表工具

本仓库保存 Electron 导表工具、Unity 开发版、配置示例、批处理脚本、需求文档和测试。

## 目录

- `src/`：Electron 主进程、界面、SVN 检测、Sheet 定位与导表逻辑。
- `一站式导表工具-开发版/`：Unity 工程源码、资源、依赖及项目设置。
- `config.xml`：导表配置示例。
- `debug_bats/`：原始批处理及历史排查样例。
- `tests/`：逻辑回归和 Electron 界面检查。
- `src/faq.html`：可独立打开的离线指南，工具首次启动自动展示；主界面「使用指南 / FAQ」或 F1 可再次打开。

依赖目录、临时日志、登录凭据和生成目录不进入 Git。依赖可通过锁文件还原；绿色版 exe 保存在仓库 Releases 中。

## 本地运行与构建

在 Windows 上安装 Node.js 后执行：

```powershell
npm ci
node scripts/prepare-svn.cjs
npm start
npm test
npm run test:ui
npm run test:faq
npm run build -- --config.directories.output=release_1.0.11
```

构建需要能下载 Electron 和 electron-builder 的 Windows 打包组件。`prepare-svn.cjs` 仅在开发机下载并校验官方 SVN 包，以 `/a` 方式解包，提取独立 CLI 和依赖，不安装系统 SVN。内网构建机可由维护人员提供已校验的 `build/svn-runtime`。打包前会校验所有运行库文件。实际导表还需要配置项目工具目录、业务脚本；图形 SVN 操作沿用电脑原有 TortoiseSVN。自动定位 Sheet 需要支持自动化的 Excel 或 WPS。

## 1.0.11 SVN 扫描容错

- SVN 状态扫描独立使用每目录 180 秒超时和 32 MB 输出缓冲，避免大量生成文件沿用版本检测的 15 秒短超时。
- 提交扫描失败显示分类、目录、原因和重试入口；命令、退出码、信号及耗时收起到技术详情。
- 区分超时、输出溢出、工作副本格式不兼容及非工作副本；配置目录不存在时明确报错，不静默遗漏。
- 扫描未成功时阻止提交；搜索、全选不会清掉错误提示，并处理 IPC 异常及重叠扫描的过期结果。
- 验证：25 项回归（含真实超时与缓冲溢出）、Electron 失败重试/异常/重叠扫描界面检查。

## 1.0.10 自动准备 SVN

- 启动时缺少命令行，自动离线准备内置组件；取消 SVN 启用弹窗和手动启用按钮。
- 日志上方以轻提示显示准备状态，成功提示 4 秒后收起；只有失败时保留原因和重试入口。
- 并发检测共用任务，准备期间导表等待完成；失败后不循环自动重试，不把失败当成就绪。
- 继续优先使用现有 SVN，不覆盖系统安装或修改系统 PATH。FAQ 同步改为自动准备说明。
- 验证包含启动无需点击、已就绪不重复准备、提示自动收起、并发去重、失败阻止导表和手动重试恢复。

## 1.0.9 离线启用 SVN 组件

- 缺少命令行时可点“一键启用内置 SVN”，离线复制工具专用组件到当前用户的工具数据目录，无需管理员权限；成功后自动检测。
- 不运行系统安装程序、不安装/升级/覆盖已有 SVN、不改系统注册表和系统 PATH；已有可用命令行优先，包括注册的自定义安装目录。
- 内置组件使用独立配置目录进行工具内的 SVN 状态检查，不自动升级工作副本。更新、提交等图形操作仍使用电脑原有 TortoiseSVN。
- 内置版本：Subversion 1.14.5，来源 TortoiseSVN 1.14.9.29743 官方 x64 包；包含依赖和原始许可文件，准备与启用时均校验哈希。
- 验证：22 项回归测试、实际离线组件运行与本地工作副本状态检查、系统 svn.exe 哈希及进程 PATH 保持不变；界面覆盖一键启用、失败重试、重复点击和自动检测。

## 1.0.8 全量导表修复

- 验证：17 项逻辑回归通过，含真实 CMD 全量分支测试；Electron 界面测试覆盖有排除、无排除、全部排除、取消和空配置。

## 1.0.7 使用体验

- 错误详情作为可折叠日志记录保存，随日志滚动；删除行号占位和固定的“查看最近错误”按钮。
- 日志区域内提供清空按钮，确认后清空日志与错误记录，不停止正在执行的导表。
- 帮助支持独立、可拖动和调整大小的窗口；主界面与帮助页均有入口，可对照操作。
- 帮助和安装提示中的 command line client tools 标红。

## 1.0.6 修复

- 空值显示为“（空值）”，区分日志未提供；兼容没有分隔空格的空值报错，保留 0 等实际值。
- 类型错误显示中文类型说明，并提供检查空白单元格的修改建议。

## 1.0.5 修复

- 重复索引报错直接提取 Excel、页签、字段和重复值；优先使用错误行自带的位置。
- 处理子进程输入流的异步错误；进程退出、管道关闭后停止写入，避免偶发 EPIPE 主进程异常。
- 正常结束不误报；异常退出且没有更具体表错误时显示中文容错弹窗，支持复制信息和查看日志。
